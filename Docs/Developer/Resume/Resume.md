## 项目经验

### 《YanGame》UE5 多人动作游戏 | 个人独立开发 | 2026.03 - 至今

> 个人长期项目，目标是在新一代 Mover 移动框架上验证「高自由度位移技能 + 可预测的多人同步」。
>
> GitHub ：https://github.com/YanLao6/YanGame
>
> BiliBili : 【14天开发，28届技术策划实习求职demo】 https://www.bilibili.com/video/BV1tTpA6yEnB/?share_source=copy_web&vd_source=b1a55a1c89d14930c06e93237e86960f

- **熟悉新插件Mover**：放弃CMC，将移动拆分为「运动模式」与「状态转移」两类原子——模式只负责本帧速度解算，转移只负责条件判定，两者均实现为无外部副作用的可重放逻辑，从而能被网络回滚正确重演。在此之上实现了滑铲（自定义摩擦衰减与坡度重力累积） 冲刺 钩锁 击飞 吸引 传送等状态。
- **熟悉网络预测**：客户端本地生成纯表现投射物（不参与复制），发射后仅将目标判定数据上传服务器；服务器复算并通过效果计算管线求解击飞向量，再以权威状态广播给所有客户端。相比复制整个投射物 Actor，把一次交互的网络开销压到「一条上行 + 一次状态复制」，同时保留了本地零延迟的手感。
- **熟悉UE Anglescript脚本**：接入社区版 AngelScript 引擎分支，把角色输入与 UI 行为下沉到脚本层，实现改动即时生效，将玩法迭代的验证周期从「重编译 + 重启编辑器」缩短到秒级。
- **熟悉Lyra的装备系统并做扩展开发：** 实现武器切换的本地预测，优化其切换手感。开发GameFeatureAction_AddItems用来开局给玩家物品，做快捷栏默认切换，增加历史切换队列，当前物品栏中的物品用完时自动切换至之前切换到的物品栏。
- **熟悉Lyra的Experience系统并做扩展开发：**扩展开发PawnData和PawnDataFragment，能够让玩家选择不同的英雄，为不同的玩家配置不同的英雄数据。
- **熟悉GAS系统：**做出多种本地，本地预测，服务器技能。
